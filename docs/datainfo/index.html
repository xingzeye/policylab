原始数据里有哪些内容

这一部分说明原始数据文件里都存了什么，以及导出成 CSV 后分别放在哪些列中。 看懂这一页后，就能知道后面的训练代码到底在读取哪些数据。

原始字段名 在 CSV 里的位置 数据大小说明 这部分表示什么 哪些算法会用到
observations obs_0 ~ obs_16 [N, 17] 环境状态向量，共 17 维 全部算法
actions act_0 ~ act_5 [N, 6] 动作向量，共 6 维，范围通常在 [-1, 1] 全部算法
rewards reward [N] 每一步对应奖励值 CQL / SAC / TD3 / DDPG 系列
next_observations 未导出到当前 CSV [N, 17] 下一时刻状态，属于 transition 信息 CQL / SAC / TD3 / DDPG 系列
terminals terminal [N] 轨迹终止标记，0/1 CQL / SAC / TD3 / DDPG 系列
导出表格怎么分块
分组名称 列名前缀 列数 列范围 说明
Observation 列 obs_ 17 obs_0 ~ obs_16 对应 HDF5 中的 observations
Action 列 act_ 6 act_0 ~ act_5 对应 HDF5 中的 actions
Reward 列 reward 1 reward 对应 HDF5 中的 rewards
Terminal 列 terminal 1 terminal 对应 HDF5 中的 terminals
算法一般会读取哪些内容
算法 通常需要的数据
BC / BC_NB observations, actions
CQL / CQL_NB observations, actions, rewards, next_observations, terminals
SAC / SAC_NB observations, actions, rewards, next_observations, terminals
TD3 / TD3_NB observations, actions, rewards, next_observations, terminals
DDPG 家族 observations, actions, rewards, next_observations, terminals
简单理解：有的算法只需要“状态和动作”，有的还需要“奖励、下一步状态、是否结束”。
