先认识三个词

看懂后面，只需要这一点基础。

01

策略 Actor / Policy

负责决定怎么做。输入当前状态，输出动作或动作分布。

02

价值 Critic / Q

负责估计值不值得。Q 值是做某个动作后，未来累计收益的估计。

03

离线数据 Dataset

BC 只用状态和动作即可学习。DDPG、TD3、SAC 原本是常见的在线交互、off-policy 方法；off-policy 并不等于天然适合固定离线数据。

模仿学习01 / 05

BC先学会模仿

看到相似的状态，就模仿数据里做过的动作。

打个比方

像跟着教练的录像学跑步：看到身体前倾，就学习教练此时如何摆腿。

它是怎么学的？

  1. 取出一条「状态 → 动作」示范。
  2. 让策略根据状态预测动作。
  3. 比较预测与示范的差距，反复缩小误差。
再多懂一点：一句公式

模仿误差 = 平均（预测动作 − 示范动作）²

误差越小，动作越像示范；它不直接判断这样做能拿多少长期奖励。

它擅长什么

结构简单，是理解其他方法的起点。

需要留意

示范不好也会照学；遇到数据中少见的状态，误差可能逐步累积。

本项目的实现 / NB

BC.py 直接拟合示范动作；BC_NB.py 按轨迹回报加权，让高回报轨迹对学习的影响更大。加权不保证实际回报一定提高。

记住这句话

BC：照着做。BC_NB：更重视高回报的示范。

继续看 BC 的代码与原理 ↗
想一想BC 的动作误差很小，是否说明实际跑得一定更好？

不一定。动作相似只说明模仿得像，真实表现还需要在环境中评估累计回报。

确定性策略02 / 05

DDPG一边行动，一边打分

策略负责出动作，评价网络负责估计这个动作的长期价值。

打个比方

像运动员和教练配合：运动员尝试摆腿方式，教练估计哪种动作更有利于接下来跑得快。

它是怎么学的？

  1. Critic 从奖励和下一状态学习动作的 Q 值。
  2. Actor 为当前状态给出一个确定的动作。
  3. 经典 DDPG 沿着 Critic 的评价改进 Actor，并缓慢更新目标网络。
再多懂一点：一句公式

评价目标 = 当前奖励 + 折扣因子 × 下一步的预计价值

Q 值看的是后续累计收益的估计；Actor 追求更高的估计值。终止状态不再计入未来价值。

它擅长什么

能直接输出连续动作，例如关节施加多大的力。

需要留意

评价可能高估，策略也可能追着错误高分走；直接用在固定离线数据上尤其需要约束。

本项目的实现 / NB

DDPG.py 已使用双 Critic、延迟更新和优势加权模仿，属于离线改写，不是原始 DDPG。DDPG_NB.py 使用 Q 导向项与 BC 正则，让策略兼顾估计收益和数据中的动作。

记住这句话

经典 DDPG：听评价改动作。本项目：再结合离线数据约束。

继续看 DDPG 的代码与原理 ↗
想一想Q 值变大，能否直接认为真实奖励提高了？

不能。Q 值是模型的估计，可能存在高估；需要独立环境评估来验证。

稳定化改进03 / 05

TD3先让评价稳下来

在 DDPG 思路上，用双评价、慢一点的策略更新和目标动作扰动减少误判。

打个比方

像请两位教练打分，参考较谨慎的那个；动作方案不用每次打分后立刻大改。

它是怎么学的？

  1. 训练两个 Critic，用较小的目标 Q 值构造学习目标。
  2. 给目标动作加小幅且受限的噪声，平滑局部尖峰。
  3. Critic 多学几步，Actor 再更新；目标网络随策略延迟更新。
再多懂一点：一句公式

目标评价参考 = min（目标 Q₁，目标 Q₂）

两个目标评价取较小值，有助于缓解高估；这仍然是估计，不是可靠性的保证。

它擅长什么

三个稳定技巧清楚，适合与 DDPG 对照学习。

需要留意

更稳不等于自动适合离线数据；策略仍可能选择数据外动作。

本项目的实现 / NB

TD3.py 实现双 Critic、目标动作平滑和延迟更新；TD3_NB.py 加入 BC 正则与 Q 项尺度平衡，让策略别轻易远离数据动作。

记住这句话

TD3：双评价、慢更新、平滑目标。TD3_NB：再加模仿约束。

继续看 TD3 的代码与原理 ↗
想一想两个 Critic 的评价应该取平均，还是取较小值构造目标？

TD3 采用较小值来构造目标，目的是缓解过高估计；Actor 的更新通常使用第一个 Critic。

随机策略04 / 05

SAC保留合理的选择余地

经典 SAC 既追求高奖励，也鼓励策略保持适度的动作多样性。

打个比方

像练跑步时保留几种合理步幅，而不是过早认定只有一个动作最好。

它是怎么学的？

  1. Actor 输出动作分布，而不是固定的一组动作。
  2. 双 Critic 学习包含熵项的长期价值目标。
  3. 经典 SAC 用价值与熵共同优化策略，温度系数控制多样性的权重。
再多懂一点：一句公式

经典 SAC 的目标 ≈ 累计奖励 + 温度系数 × 策略熵

熵可以理解为动作选择的多样性。温度权重大时，更重视保留选择；它不是随便乱做动作。

它擅长什么

随机策略能表达多种动作选择，经典版本常用于连续控制。

需要留意

固定离线训练不会因策略随机就获得新数据；数据外动作依然可能被错误评价。

本项目的实现 / NB

SAC.py 的 Actor 使用优势加权的数据动作对数似然，属于 AWAC 风格改写；SAC_NB.py 使用 SAC 目标加 BC 正则。这两份实现不只是同一损失上简单加减一项。

记住这句话

经典 SAC：收益与多样性兼顾。本项目：关注具体的离线 Actor 目标。

继续看 SAC 的代码与原理 ↗
想一想离线 SAC 有随机策略，就能主动去环境里探索吗？

不能。离线训练只使用已有数据；策略有随机性与训练时能否采集新数据是两件事。

离线强化学习05 / 05

CQL对陌生动作谨慎打分

给 Q 学习加入保守约束，减少对缺少数据支持的动作的过高估计。

打个比方

像只看训练录像的教练：对录像里几乎没见过的高难度动作，不能凭想象给出很高分。

它是怎么学的？

  1. 用已有转移数据学习 Critic 的价值目标。
  2. 比较采样候选动作与数据动作的 Q 值，加入保守惩罚。
  3. 策略根据受到约束的评价学习，减少利用虚假高分的机会。
再多懂一点：一句公式

Critic 损失 = 价值拟合误差 + 保守惩罚的加权项

保守项抑制缺少支持的高估，同时相对保留数据动作的价值；不是把所有 Q 值一律压低。

它擅长什么

直接针对离线学习中的分布外动作高估问题。

需要留意

约束太强可能过于保守；保守项变小本身不能证明策略更好。

本项目的实现 / NB

CQL.py 与 CQL_NB.py 都有保守价值学习和 BC 相关约束。NB 版进一步调整保守项计算与 Q / BC 尺度平衡；它是项目实现的变体，不等同于复现论文的全部设定。

记住这句话

CQL：陌生动作别虚高。本项目 NB：继续调整约束与学习尺度。

继续看 CQL 的代码与原理 ↗
想一想CQL 的保守惩罚越大，策略就一定越好吗？

不一定。过强的保守约束可能压制有效改进，应结合稳定性与独立回报评估判断。
